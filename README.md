# Deadlock Top Builds

Live top daily, weekly and monthly community builds for each Deadlock hero, ranked by games played,
with win rates and BuildIDs. Data comes from [deadlock-api.com](https://deadlock-api.com).

Open it at https://run180.github.io/deadlock-top-builds/ or inside Deadlock with the Top Builds button mod
(the page loads with `#ingame` there; clicking a BuildID opens that build in Browse Builds).
